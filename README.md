# 早八生存局——今天翘不翘？

一个面向《博弈论》/《微观经济学》课堂的扫码实时联机实验游戏，用「早八去上课还是翘课」直观讲透**不完全信息静态博弈**与**贝叶斯纳什均衡（BNE）**。

老师开房并投影大屏，学生手机扫码入局。每局系统暗中发放私人角色牌，全班在倒计时内同时选择「去上课」或「翘课」，服务器按公开的点名规则结算积分，大屏实时公布结果、分类型统计与排行榜，并支持按键一键切换内置 5 页交互式课堂 PPT。

## 核心功能

- **主持台 & 学生端实时联机**：老师创房设 PIN、调规则、开局、收卷、结算、放榜；学生扫码或输 4 位房间码免注册入座，支持断线重连。
- **三种主玩法**（大厅选定，局间可切）：
  - **起床战争**：经典单堂局，聚焦标准贝叶斯纳什均衡。
  - **点名风云**：两堂连战（固定同一角色），首堂点名结果与出勤率动态修正第二堂点名率。
  - **代勤者联盟**：双人随机配对 + 声誉机制；点名后到课队友可选择是否替翘课队友答“到”，老师按被代勤者声誉随机复查。
- **四种点名模式**：
  - **必点**（$q = 1$）、**必不点**（$q = 0$）、**概率点名**（$q = \text{全班翘课率}$）、**阈值点名**（出勤率低于 $\tau$ 时以 $q_0 = 1 - \text{心情}/100$ 抽查，心情可选 90 / 70 / 50）。
- **发牌模式与有限人数 BNE 引擎**：
  - 支持**固定牌库**（默认，按精确配额洗牌）与**独立抽取**两种发牌方式。
  - 按当前班级参战人数与发牌方式实时计算对称贝叶斯纳什均衡，并支持启用「随缘翘课签」辅助混合策略随机化。
- **内置 5 页交互课堂 PPT**：主持台默认开启教学模式，按 `G` 键秒切大屏，支持 KaTeX 数学公式、步骤逐帧推导、发牌树/无差异天平/二项分布沙盘交互，以及读取本班实战历史的实时对照条。
- **彩排工具 & 隐私隔离**：主持台仅做全局控制与聚合统计，不展示个人底牌、理由与选择；内置机器人批处理方便课前单人彩排。

## 快速开始

需要 Node.js 22+。

```bash
npm install
npm run dev
```

- 前端开发地址：`http://localhost:5173`
- 后端服务地址：`http://localhost:3000`

生产构建与启动：

```bash
npm run build
npm start
```

打开浏览器访问 `http://localhost:3000`，点击「我是老师，开一局」即可开房。

> **局域网使用提示**：主持台检测到 `localhost` 时会自动把大屏二维码替换为本机局域网 IP；学生连接同一校园网或 Wi-Fi 即可扫码入座（若改用局域网地址打开主持台，重输 4 位 PIN 即可接管）。

## 玩法与默认参数

| 角色 | 类型 | 上课成本 | 点名去课 | 不点去课 | 点名翘课 | 不点翘课 |
| :--- | :---: | :---: | :---: | :---: | :---: | :---: |
| 早起自律人 | $L$ | 3 | +7 | +3 | -5 | +5 |
| 起床困难户 | $H$ | 6 | +4 | 0 | -5 | +5 |

默认设置：
- **主玩法**：起床战争；**点名模式**：必点（热身基准）；
- **困难户比例**：40%；**发牌方式**：固定牌库（可切独立抽取）；
- **阈值点名预设**：出勤率低于 70% 触发、老师心情 50（抽查概率 50%）；
- **每轮时长**：120 秒（超时未选按翘课处理，积分跨局累计）；
- **教学模式**：默认开启（快捷键 `G` / `←` `→` / `1`–`5` / `Esc`）；
- **理论卡片**：默认隐藏，按需在主持人设置抽屉中开启。

更多规则细节与课堂讲授脚本见：
- [教师手册](docs/教师手册.md) —— 课前准备、三种玩法与公式说明、常见问答与课堂流程
- [课堂讲义](docs/课堂讲义.md) —— 统一符号表与 5 页内置交互 PPT 逐页讲稿

## 技术结构

- **前端**：React 19 + TypeScript + Vite + Motion + KaTeX + Socket.IO Client；字体资源自托管于 `public/fonts/`。
- **服务端**：TypeScript + Express 5 + Socket.IO，单进程内存房间。
- **共用理论引擎**：`server/bne.ts` 提供有限人数精确 BNE 求解，`server/game.ts` 负责状态流转、点名结算、代勤与排名。
- **角色文案**：`data/早起自律人.txt` 与 `data/起床困难户.txt`（每行一条），服务端启动时加载（首页静态卡片随前端构建打包）。

目录结构：

```text
server/        Express API、Socket.IO、游戏引擎与 BNE 求解器
src/           React 页面、主持台、学生端与 5 页交互课件
data/          两类角色的课堂文案池
docs/          教师手册与课堂讲义
scripts/       游戏逻辑单测、端到端冒烟与 Socket.IO 压测脚本
public/        站点图标与自托管 Noto CJK 字体子集
```

## 测试与压测

```bash
npm run typecheck  # 前后端与脚本 TypeScript 类型检查
npm test           # 游戏逻辑、有限人数 BNE、代勤/回笼觉等单元测试
npm run smoke      # 启动临时服务走通开房、加入、发牌、摇签、收卷与结算
npm run loadtest   # Socket.IO 并发压测（默认 40 人，可通过 LOAD_PLAYERS=120 调整）
```

## 部署

### Docker 部署

项目根目录提供多阶段 [Dockerfile](Dockerfile)，可用于单容器打包构建与运行：

```bash
docker build -t zaoba-survival .
docker run --rm -p 3000:3000 zaoba-survival
```

自定义端口或监听地址：

```bash
docker run --rm -p 8080:8080 -e PORT=8080 zaoba-survival
```

### Node.js 直接运行

```bash
HOST=0.0.0.0 PORT=8080 npm start
```

> 若前置 Nginx / Caddy 反向代理，请注意转发 `/socket.io` 的 WebSocket 连接。房间状态保存在内存中，重启后会清空。
